# MVMAE

The source code of our TNNLS-2026 paper "Efficient and Scalable Multi-View Masked Autoencoder for Heterogeneous Graph Self-Supervised Learning".

## Dataset

The ACM, DBLP, Freebase datasets can be downloaded from HGMAE's official repository:
https://github.com/meettyj/HGMAE

The Freebase dataset can be download from HIN-Datasets:
https://github.com/librahu/HIN-Datasets-for-Recommendation-and-Network-Embedding

The RCDD dataset can be download by torch-geometric:
https://pytorch-geometric.readthedocs.io/en/latest/generated/torch_geometric.datasets.RCDD.html

## How to run

You can run "python train.py" with arguments to train the model.
